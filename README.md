# bunyan-docs

Public pages for **بنيان (Bunyan)**, an Arabic-first strength-training app for Android
(`com.midoshehaa.fitnessapp`).

This repository holds only the documents that have to be reachable from a public URL — the
privacy policy Google Play requires. The app's source lives in a private repository and is not
part of this one.

## What is here

| Path | Page |
| --- | --- |
| `index.html` | Landing page |
| `privacy-policy/index.html` | Privacy policy, Arabic and English |

Both pages are self-contained: no external fonts, scripts or stylesheets, so a privacy policy of
all things does not itself send a request to a third party. They follow the reader's light/dark
preference.

## Published at

```
https://midoshehaa.github.io/bunyan-docs/
https://midoshehaa.github.io/bunyan-docs/privacy-policy/
```

Served by GitHub Pages from the `main` branch, root folder.

## Changing the policy

The policy's source of truth is `PRIVACY_POLICY.md` in the app repository, kept in step with what
the app actually does. Edit it there first, then carry the change into
`privacy-policy/index.html` here so the published page and the app never drift apart.
